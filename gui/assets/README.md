# SoundLink app icon

Designed with the built-in image generation tool. The opaque navy background
and teal waveform match the receiver GUI; the arcs suggest signal reception.

`soundlink-icon-original.png` preserves the original generated artwork.
`AppIcons.xcassets/AppIcon.appiconset/soundlink-icon.png` is the 1024-pixel
iOS icon. CMake packages this asset catalog and selects `AppIcon`.

Generation prompt:

Use case: logo-brand. Asset type: finished iOS app icon for SoundLink, an acoustic digital modem receiver with spectrum and constellation displays. Create one polished 1024x1024 square icon, edge-to-edge opaque deep midnight navy background. A bold distinctive central turquoise signal mark combining a smooth sinusoidal wave with two clean radiating arcs, subtle luminous mint highlights and restrained dimensional depth. Elegant precision instrument feel, simple strong silhouette recognizable at tiny sizes. Match a dark navy and mint teal technical GUI. Center the mark with generous 18 percent safe margins. No text, no letters, no numbers, no border, no mockup, no extra symbols, no baked rounded corners; square canvas, operating system applies corner mask. Premium restrained design.
